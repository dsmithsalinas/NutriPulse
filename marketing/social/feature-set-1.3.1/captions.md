# Feature set — Footing 1.3.1

Ten creatives that walk through what Footing does, in the same design language as the 1.3.1
launch video: Daylight palette, Bricolage Grotesque and Figtree, real screens on an iPhone, and
Pulse doing the talking. Voice per `../../site-v2-voice.md` and `../../../docs/pulse-persona.md`:
sentence case, no exclamation marks, no banned words, zero emoji.

TestFlight). Every image carries the same "Join the beta · tryfooting.app" pill.

## Notes

**Medication names.** The Shot day screen shows "GLP-1 · 5 mg" here, not the brand the sample account uses. The original screenshot's brand name was replaced in the app's own font so no image names a prescription drug (Meta restricts prescription-drug promotion; see `../../instagram-launch-posts.md`). Keep it that way if a screen is ever recaptured: the sample account's Shot day and Profile screens both show a brand name.

**Health claims.** None. Every line describes what the app does, not an outcome. "You're there, with dinner still ahead" replaces a muscle-protection line for this reason.

**Sample data.** All screens use the app's built-in preview data, not a real user's. No testimonials.

**Stories.** Headlines and the call to action sit between 250px from the top and 340px from the bottom, clear of Instagram's own controls.
